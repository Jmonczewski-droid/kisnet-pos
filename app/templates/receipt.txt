# KISnet-POS guest receipt template.
#
# Edit this file to change what prints on the guest receipt. Changes take effect
# on the next receipt; no restart is needed.
#
#   - Lines starting with # are notes and are not printed.
#   - A line starting with ^ is centered. A line starting with ! is centered, bold and large.
#   - A line of only dashes (----) prints a divider across the paper.
#   - Words in {braces} are filled in by the POS:
#       {seat}  {party_name}  {party_size}  {server_name}
#       {date}  {time}  {order_number}
#       {items}   one line per item: quantity, name, line price (put it on a line by itself)
#       {item_count}  {total}
#   - "Left text | right text" puts the right text at the right edge of the paper.
#
# The POS does not calculate tax or tips yet, so there are no fields for them.
